# 🎵 YouTube Video İndirici 🎥

## 📝 Proje Açıklaması

YouTube videolarını MP3 ve MP4 formatında indirmenize olanak sağlayan modern, kullanıcı dostu bir web uygulamasıdır.

### ✨ Özellikler

- 🔗 YouTube URL'sinden video indirme
- 🎧 MP3 formatında ses indirme
- 📹 MP4 formatında video indirme
- 📱 Responsive ve iOS tarzı arayüz
- 🚀 Hızlı ve güvenilir indirme
- 🛡️ Gelişmiş hata yakalama

## 🛠️ Teknolojiler

### Frontend

- HTML5
- CSS3
- Vanilla JavaScript

### Backend

- Python
- Flask
- yt-dlp

## 🚀 Kurulum

### Ön Gereksinimler

- Python 3.8+
- pip

### Backend Kurulumu

1. Proje dizinine gidin

```bash
cd backend
```

2. Sanal ortam oluşturun

```bash
python -m venv venv
```

3. Sanal ortamı etkinleştirin

- Windows:

```bash
venv\Scripts\activate
```

- macOS/Linux:

```bash
source venv/bin/activate
```

4. Bağımlılıkları yükleyin

```bash
pip install -r requirements.txt
```

## 🔧 Çalıştırma

### Backend Sunucusu

```bash
python app.py
```

### Frontend

`frontend/index.html` dosyasını tarayıcınızda açın.
